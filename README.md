# KalaOS Portfolio

KalaOS is Kalaab Alebachew’s visual portfolio and profile experience, published with GitHub Pages. The site introduces selected software projects and provides access to a CV.

## Contents

- `index.html` — portfolio page and social preview metadata.
- `og.png` — Open Graph preview image.
- `cv/Kalaab_Alebachew_CV.pdf` — downloadable CV.

## Local preview

This is a static site. Open `index.html` in a browser or run any static file server from the repository root.

## Deployment

GitHub Pages publishes the `main` branch from the repository root at [kalaabalb.github.io](https://kalaabalb.github.io).
